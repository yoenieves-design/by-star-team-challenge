# Cloudflare integration boundary

The WordPress demo serves a static application and prebuilt JSON streams. The browser replays the packets, evaluates illustrative rules and saves progress locally. It requires no Cloudflare Worker.

A Worker could be considered later for importing a public dataset or exchanging a reviewed report with a terrestrial service. The concept places continuous health and environmental monitoring inside the mission network so it can keep running when the Earth link is unavailable. See [architecture](../docs/ARCHITECTURE.md).
